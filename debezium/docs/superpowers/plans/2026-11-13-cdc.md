# Local CDC Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 本机运行 PostgreSQL → Debezium → Kafka → Python → Redis，并部署 RabbitMQ。
**Architecture:** Homebrew Kafka 和 RabbitMQ；目录内独立 PG18 与 Connect standalone；Python 串行处理并手动提交。
**Tech Stack:** PostgreSQL 18, Kafka 4.4, Debezium 3.7.1.Final, Python 3.14, kafka-python, psycopg, redis。
**Spec:** ../specs/2026-11-13-cdc-design.md

## Global Constraints
- uid uuid，默认 uuidv7()；Python 八空格缩进，单引号。
- 不修改现有 PG5432，不清空 Redis，不触碰用户已有 Git 改动。
- 实际写 Redis 成功之后提交 offset；未知事件和坏消息失败退出。

## Review Focus
- tombstone 不可重新 SET，也不可覆盖更新。
- Redis 失败不可提交后续 offset。
- DELETE 从消息 key 取 uid，不依赖 before 全量数据。
- 进程重启不重新格式化 Kafka/数据库、不重置 offset。
- 追赶验证必须真实停止消费者，期间修改数据库，再恢复。
