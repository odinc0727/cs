## 一. 进程的概念

进程是操作系统中正在执行的程序实例，是系统进行资源分配的基本单位。每个进程都有独立的内存空间、文件描述符表、进程ID等资源。

### 进程的主要状态

进程状态通常由一个字母表示，最常见的包括：

| 状态      | 符号                  | 名称                  | 描述                                                                                                                |
| --------- | --------------------- | --------------------- | ------------------------------------------------------------------------------------------------------------------- |
| ​**​R​**​ | Running / Runnable    | ​**​运行中/可运行​**​ | 进程正在 CPU 上执行或就在运行队列中等待被调度执行。                                                                 |
| ​**​S​**​ | Interruptible Sleep   | ​**​可中断睡眠​**​    | 进程正在等待某个事件完成（如 I/O 操作、信号、网络数据）。在这种状态下可以被信号唤醒。                               |
| ​**​D​**​ | Uninterruptible Sleep | ​**​不可中断睡眠​**​  | 进程正在等待硬件 I/O 条件（通常是磁盘 I/O），​**​不会响应任何信号​**​（即使是 `kill -9`）。这是为了确保数据一致性。 |
| ​**​T​**​ | Stopped               | ​**​暂停/跟踪​**​     | 进程被信号（如 `SIGSTOP`）暂停，或者正在被调试器（如 gdb）跟踪。可以通过 `SIGCONT`信号继续执行。                    |
| ​**​Z​**​ | Zombie                | ​**​僵尸​**​          | 进程已终止，但其退出状态尚未被父进程读取（通过 `wait()`）。它保留在进程表中直到父进程回收它。                       |
| ​**​X​**​ | Dead                  | ​**​死亡​**​          | 进程已完全死亡，即将从进程表中被清除。这个状态很难被观察到，因为它存在的时间极短。                                  |

### 状态转换示意图

```
[新建] -> [R (可运行)] -> [R (运行中)] <--> [S/D (睡眠)] -> [Z (僵尸)] -> [X (死亡)]
                 |
                 v
             [T (暂停)]
```

- ​**​新建 (New)​**​：进程刚被创建（`fork()`）。

- ​**​可运行 (R)​**​：进程准备好被 CPU 执行。

- ​**​睡眠 (S/D)​**​：进程等待事件，让出 CPU。
     - ​**​S​**​：可中断睡眠（可被信号唤醒）。
     - ​**​D​**​：不可中断睡眠（通常等待磁盘 I/O）。
- ​**​暂停 (T)​**​：进程被调试器或 `SIGSTOP`信号暂停。
- ​**​僵尸 (Z)​**​：进程已结束，等待父进程回收。
- ​**​死亡 (X)​**​：进程被完全清除。

## 三. 进程同步及进程通信(IPC)

### 1. 进程同步 - 信号量

- 防止数据竞争(Data Race)
- 确保共享资源的一致性
- 协调进程间的执行顺序

信号量是一种计数器，用于控制对共享资源的访问。它主要用于进程同步，确保多个进程对临界资源的互斥访问。信号量支持两种基本操作：wait操作（等待/减1）和post操作（信号/加1）。

- 进程互斥（多个进程操作同一个资源）- 初始值为1的信号量
- 进程限制（多个进程操作若干资源）- 普通信号量

#### API函数

| 函数名          | 功能描述             |
| --------------- | -------------------- |
| `sem_open()`    | 创建或打开命名信号量 |
| `sem_init()`    | 初始化无名信号量     |
| `sem_wait()`    | 等待信号量（P操作）  |
| `sem_post()`    | 释放信号量（V操作）  |
| `sem_close()`   | 关闭信号量           |
| `sem_unlink()`  | 删除命名信号量       |
| `sem_destroy()` | 销毁无名信号量       |

#### 代码示例

**命名信号量示例：**

```c
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <semaphore.h>
#include <fcntl.h>
#include <sys/wait.h>

#define SEM_NAME "/my_semaphore"

int main() {
    sem_t *sem;

    // 创建命名信号量
    sem = sem_open(SEM_NAME, O_CREAT | O_EXCL, 0644, 1);
    if (sem == SEM_FAILED) {
        // 如果信号量已存在，先删除再创建
        sem_unlink(SEM_NAME);
        sem = sem_open(SEM_NAME, O_CREAT | O_EXCL, 0644, 1);
        if (sem == SEM_FAILED) {
            perror("sem_open failed");
            return 1;
        }
    }

    if (fork() == 0) {
        // 子进程
        printf("子进程等待信号量...\n");

        // 等待信号量（P操作）
        if (sem_wait(sem) == -1) {
            perror("sem_wait failed");
            exit(1);
        }

        printf("子进程获得信号量，进入临界区\n");
        sleep(3);
        printf("子进程离开临界区\n");

        // 释放信号量（V操作）
        if (sem_post(sem) == -1) {
            perror("sem_post failed");
            exit(1);
        }

        // 关闭信号量
        sem_close(sem);
        exit(0);
    } else {
        // 父进程
        sleep(1);
        printf("父进程等待信号量...\n");

        // 等待信号量（P操作）
        if (sem_wait(sem) == -1) {
            perror("sem_wait failed");
            return 1;
        }

        printf("父进程获得信号量，进入临界区\n");
        sleep(2);
        printf("父进程离开临界区\n");

        // 释放信号量（V操作）
        if (sem_post(sem) == -1) {
            perror("sem_post failed");
            return 1;
        }

        // 等待子进程结束
        wait(NULL);

        // 关闭并删除信号量
        sem_close(sem);
        sem_unlink(SEM_NAME);
    }

    return 0;
}
```

### 2. 共享内存

共享内存是最快的IPC方式，它允许多个进程访问同一块物理内存区域。进程可以直接读写共享内存，无需系统调用开销。但需要使用同步机制（如信号量）来协调对共享内存的访问。

#### API函数

| 函数名         | 功能描述                       |
| -------------- | ------------------------------ |
| `shm_open()`   | 创建或打开共享内存对象         |
| `ftruncate()`  | 设置共享内存大小               |
| `mmap()`       | 将共享内存映射到进程地址空间   |
| `munmap()`     | 从进程地址空间解除共享内存映射 |
| `shm_unlink()` | 删除共享内存对象               |

#### 代码示例

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>
#include <sys/mman.h>
#include <sys/stat.h>
#include <fcntl.h>
#include <sys/wait.h>

#define SHM_NAME "/my_shared_memory"
#define SHM_SIZE 1024

int main() {
    int shm_fd;
    char *shm_ptr;

    // 创建共享内存对象
    shm_fd = shm_open(SHM_NAME, O_CREAT | O_RDWR, 0666);
    if (shm_fd == -1) {
        perror("shm_open failed");
        return 1;
    }

    // 设置共享内存大小
    if (ftruncate(shm_fd, SHM_SIZE) == -1) {
        perror("ftruncate failed");
        return 1;
    }

    // 映射共享内存到进程地址空间
    shm_ptr = (char*)mmap(NULL, SHM_SIZE, PROT_READ | PROT_WRITE,
                         MAP_SHARED, shm_fd, 0);
    if (shm_ptr == MAP_FAILED) {
        perror("mmap failed");
        return 1;
    }

    if (fork() == 0) {
        // 子进程写入数据
        strcpy(shm_ptr, "Hello from child process!");
        printf("子进程写入: %s\n", shm_ptr);

        // 解除映射
        munmap(shm_ptr, SHM_SIZE);
        close(shm_fd);
    } else {
        // 父进程读取数据
        sleep(1);
        printf("父进程读取: %s\n", shm_ptr);

        // 等待子进程结束
        wait(NULL);

        // 解除映射并删除共享内存
        munmap(shm_ptr, SHM_SIZE);
        close(shm_fd);
        shm_unlink(SHM_NAME);
    }

    return 0;
}
```

#### 使用二进制信号量，给共享内存做进程同步

同步顺序：子进程先运行，子进程运行结束运行父进程

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>
#include <sys/mman.h>
#include <sys/stat.h>
#include <fcntl.h>
#include <sys/wait.h>
#include <semaphore.h>

#define SHM_NAME "/my_shared_memory"
#define SHM_SIZE 1024
#define SEM_NAME "/my_semaphore"

int main() {
    int shm_fd;
    char *shm_ptr;
    sem_t *sem;

    // 创建或打开信号量
    sem = sem_open(SEM_NAME, O_CREAT, 0644, 0);
    if (sem == SEM_FAILED) {
        perror("sem_open failed");
        exit(EXIT_FAILURE);
    }

    // 创建共享内存对象
    shm_fd = shm_open(SHM_NAME, O_CREAT | O_RDWR, 0666);
    if (shm_fd == -1) {
        perror("shm_open failed");
        sem_close(sem);
        sem_unlink(SEM_NAME);
        return 1;
    }

    // 设置共享内存大小
    if (ftruncate(shm_fd, SHM_SIZE) == -1) {
        perror("ftruncate failed");
        sem_close(sem);
        sem_unlink(SEM_NAME);
        close(shm_fd);
        shm_unlink(SHM_NAME);
        return 1;
    }

    // 映射共享内存
    shm_ptr = (char*)mmap(NULL, SHM_SIZE, PROT_READ | PROT_WRITE,
                         MAP_SHARED, shm_fd, 0);
    if (shm_ptr == MAP_FAILED) {
        perror("mmap failed");
        sem_close(sem);
        sem_unlink(SEM_NAME);
        close(shm_fd);
        shm_unlink(SHM_NAME);
        return 1;
    }

    // 创建子进程
    if (fork() == 0) {
        // 子进程写入数据
        strcpy(shm_ptr, "Hello from child process!");
        printf("子进程写入: %s\n", shm_ptr);

        // 通知父进程已完成写入
        sem_post(sem);

        // 子进程清理资源
        munmap(shm_ptr, SHM_SIZE);
        close(shm_fd);
        sem_close(sem); // 只关闭，不unlink
        printf("子进程结束\n");
        exit(0);
    } else {
        // 父进程等待子进程信号
        sem_wait(sem);

        // 父进程读取数据
        printf("父进程读取: %s\n", shm_ptr);

        // 等待子进程结束
        wait(NULL);

        // 父进程清理所有资源
        munmap(shm_ptr, SHM_SIZE);
        close(shm_fd);
        shm_unlink(SHM_NAME);

        sem_close(sem);
        sem_unlink(SEM_NAME); // 由父进程负责删除信号量
        printf("父进程结束\n");
    }

    return 0;
}
```

### 3. 消息队列

对于消息队列，POSIX提供了消息队列API，但在实际应用中，更常用的是其他IPC机制如管道、套接字或现代的消息传递库。以下是POSIX消息队列的示例：

#### API函数

| 函数名         | 功能描述           |
| -------------- | ------------------ |
| `mq_open()`    | 创建或打开消息队列 |
| `mq_send()`    | 向消息队列发送消息 |
| `mq_receive()` | 从消息队列接收消息 |
| `mq_close()`   | 关闭消息队列       |
| `mq_unlink()`  | 删除消息队列       |
| `mq_getattr()` | 获取消息队列属性   |
| `mq_setattr()` | 设置消息队列属性   |

### 属性结构体

```c
struct mq_attr {
  long mq_flags; /* Message queue flags: 0 or O_NONBLOCK */
  long mq_maxmsg; /* Maximum number of messages on queue */
  long mq_msgsize; /* Maximum message size (in bytes) */
  long mq_curmsgs; /* Number of messages currently in queue */
};
```

1. **​`mq_flags`​**​: 标志位，通常设为 `0`（阻塞模式）或 `O_NONBLOCK`（非阻塞模式）。​**​这是唯一一个可在队列创建后修改的属性。​**​
2. **​`mq_maxmsg`​**​: 队列的最大容量，即能存放的消息总数。​**​必须在创建时设定，之后不可更改。​**​
3. **​`mq_msgsize`​**​: 单条消息允许的最大字节数。​**​必须在创建时设定，之后不可更改。​**
4. **​`mq_curmsgs`​**​: 当前队列中已有的消息数量。​**​只读​**​，由内核自动更新。

#### 代码示例

```c
#include <fcntl.h>
#include <mqueue.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <sys/stat.h>
#include <sys/wait.h>
#include <unistd.h>

#define QUEUE_NAME "/my_message_queue"
#define MAX_SIZE 1024
#define MSG_STOP "exit"

int main() {
  mqd_t mq;
  struct mq_attr attr;
  char buffer[MAX_SIZE + 1];
  const char *message = "Hello from parent process!";

  // 设置消息队列属性
  attr.mq_flags = 0;
  attr.mq_maxmsg = 10;
  attr.mq_msgsize = MAX_SIZE;
  attr.mq_curmsgs = 0;

  // 创建消息队列
  mq = mq_open(QUEUE_NAME, O_CREAT | O_RDWR, 0644, &attr);
  if (mq == (mqd_t)-1) {
    perror("mq_open failed");
    return 1;
  }

  if (fork() == 0) {
while (1) {
  // 子进程：接收消息
  ssize_t bytes_read = mq_receive(mq, buffer, MAX_SIZE, NULL);
    if (bytes_read == -1) {
      perror("mq_receive failed");
      exit(1);
    }
    buffer[bytes_read] = '\0';
    printf("子进程接收消息: %s\n", buffer);
    if(strncmp(buffer, MSG_STOP, strlen(MSG_STOP)) == 0) {
      break;
    }
}

    mq_close(mq);
    exit(0);
  } else {
    for (int i = 0; i < 3; i++) {
      if(i == 2){
        message = MSG_STOP;
      }
      // 父进程：发送消息
      if (mq_send(mq, message, strlen(message), 0) == -1) {
        perror("mq_send failed");
        return 1;
      }
      printf("父进程发送消息: %s\n", message);
    }
    // 等待子进程结束
    wait(NULL);

    // 关闭并删除消息队列
    mq_close(mq);
    mq_unlink(QUEUE_NAME);
  }

  return 0;
}
```

### 4. 管道

管道是UNIX系统中最古老的 IPC 形式，分为匿名管道和命名管道。匿名管道只能在有亲缘关系的进程间使用，而命名管道可以在任意进程间使用。

管道是半双工的，数据只能单向流动。如果需要双向通信，需要创建两个管道。

#### API函数

| 函数名     | 功能描述           |
| ---------- | ------------------ |
| `pipe()`   | 创建匿名管道       |
| `mkfifo()` | 创建命名管道(FIFO) |
| `open()`   | 打开命名管道       |
| `read()`   | 从管道读取数据     |
| `write()`  | 向管道写入数据     |
| `close()`  | 关闭管道           |
| `unlink()` | 删除命名管道       |
