## 一. 线程的概念

线程（Thread）是操作系统能够进行运算调度的最小单位。一个进程内的线程共享进程的内存空间、文件描述符等资源，但每个线程都有自己独立的栈空间和程序计数器。

### Linux 进程和线程

#### 核心概念：task_struct

```c
struct task_struct {
    int pid;                      // 进程ID
    int tgid;                     // 线程组ID
    struct mm_struct *mm;         // 内存管理结构
    struct files_struct *files;   // 文件描述符表
    struct fs_struct *fs;         // 文件系统信息
    struct signal_struct *signal; // 信号处理
    // ... 其他字段
};
```

- **pid**：每个task都有唯一的进程ID
- **tgid**：线程组ID，同一进程内的所有线程共享相同的tgid
- **mm**：内存管理结构，决定是否共享地址空间
- **files**：文件描述符表，决定是否共享打开的文件
- **signal**：信号处理结构，决定信号处理方式

#### clone()系统调用：统一的创建机制

##### 函数原型

```c
long clone(unsigned long flags, void *child_stack,
          int *ptid, int *ctid,
          unsigned long newtls);
```

通过不同的`flags`组合，`clone()`可以创建不同类型的执行实体：

```c
// 创建传统进程（fork的实现）
clone(SIGCHLD, 0, NULL, NULL, 0);

// 创建线程（pthread_create的底层实现）
clone(CLONE_VM | CLONE_FS | CLONE_FILES | CLONE_SIGHAND |
      CLONE_THREAD | CLONE_SYSVSEM | CLONE_SETTLS |
      CLONE_PARENT_SETTID | CLONE_CHILD_CLEARTID,
      stack, &ptid, &ctid, newtls);
```

##### 重要标志位含义

| 标志位        | 含义               |
| ------------- | ------------------ |
| CLONE_VM      | 共享虚拟内存       |
| CLONE_FILES   | 共享文件描述符表   |
| CLONE_FS      | 共享文件系统信息   |
| CLONE_SIGHAND | 共享信号处理器     |
| CLONE_THREAD  | 放入同一线程组     |
| CLONE_SYSVSEM | 共享System V信号量 |

## 二. UNIX线程的创建和销毁

### 线程创建和销毁API函数表

| 函数名             | 功能描述                         |
| ------------------ | -------------------------------- |
| `pthread_create()` | 创建一个新线程                   |
| `pthread_exit()`   | 终止当前线程                     |
| `pthread_join()`   | 等待指定线程结束并回收资源       |
| `pthread_detach()` | 分离线程，使其结束时自动回收资源 |
| `pthread_self()`   | 获取当前线程ID                   |
| `pthread_cancel()` | 取消指定线程                     |

### 代码示例

```c
#include <pthread.h>
#include <stdio.h>
#include <unistd.h>

// 无参数线程函数
void *func(void *arg) {
  pthread_t thread_id = pthread_self();
  printf("Thread %lu is running\n", (unsigned long)thread_id);
  sleep(1);
  printf("Thread %lu is exiting\n", (unsigned long)thread_id);
  pthread_exit(NULL);
}

struct data_t {
  int a;
  int b;
  int c;
  int result;
};

// 有参数线程函数
void *add(void *arg) {
  struct data_t *data = (struct data_t *)arg;
  pthread_t thread_id = pthread_self();
  printf("Thread %lu is running\n", (unsigned long)thread_id);
  data->result = data->a + data->b + data->c;
  printf("Thread %lu is exiting\n", (unsigned long)thread_id);
  pthread_exit(NULL);
}

int main() {
  pthread_t thread1;
  pthread_t thread2;
  struct data_t data = {1, 2, 3, 0};
  pthread_create(&thread1, NULL, func, NULL);
  pthread_create(&thread2, NULL, add, &data);
  pthread_join(thread1, NULL);
  pthread_join(thread2, NULL);
  printf("Result of addition: %d\n", data.result);
  return 0;
}
```

## 三. 线程同步

### 线程同步的目的

- 防止数据竞争(Data Race)
- 确保共享资源的一致性
- 协调线程间的执行顺序

### 应用场景

- 多线程操作共享变量

### 常用同步手段

- **互斥锁(Mutex)**: 保证同一时间只有一个线程访问共享资源
- **条件变量(Condition Variable)**: 线程间的通信和等待机制

以下是没有线程同步的代码

```c
#include <pthread.h>
#include <stdio.h>
#include <unistd.h>

int var = 0;

// 线程1：将变量设置为1
void *set_to_one(void *arg) {
  var = 1;
  usleep(1); // 模拟一些处理时间
  printf("thread1 var :%d\n", var);
  pthread_exit(NULL);
}

// 线程2：将变量设置为2
void *set_to_two(void *arg) {
  var = 2;
  usleep(1); // 模拟一些处理时间
  printf("thread2 var :%d\n", var);
  pthread_exit(NULL);
}

int main() {
  pthread_t thread1, thread2;
  pthread_create(&thread1, NULL, set_to_one, NULL);
  pthread_create(&thread2, NULL, set_to_two, NULL);
  pthread_join(thread1, NULL);
  pthread_join(thread2, NULL);
  return 0;
}
```

以上程序会出现线程1修改var成1以后却读到了2，或者线程2修改了var成2以后却读到了1。这就是线程未同步造成的问题。

### 1. 互斥锁（Mutex）

互斥锁是一种同步原语，用于保护共享资源，确保同一时间只有一个线程能够访问被保护的代码段。当一个线程获得锁时，其他试图获得同一锁的线程将被阻塞，直到锁被释放。

#### 互斥锁API函数表

| 函数名                    | 功能描述             |
| ------------------------- | -------------------- |
| `pthread_mutex_init()`    | 初始化互斥锁         |
| `pthread_mutex_destroy()` | 销毁互斥锁           |
| `pthread_mutex_lock()`    | 加锁（阻塞式）       |
| `pthread_mutex_trylock()` | 尝试加锁（非阻塞式） |
| `pthread_mutex_unlock()`  | 解锁                 |

#### 互斥锁代码示例

**基于之前没有线程同步的代码改进**

```c
#include <pthread.h>
#include <stdio.h>
#include <unistd.h>

int var = 0;

// 定义一个全局互斥锁
pthread_mutex_t mutex;

// 线程1：将变量设置为1
void *set_to_one(void *arg) {
  pthread_mutex_lock(&mutex); // 加锁
  var = 1;
  usleep(1); // 模拟一些处理时间
  printf("thread1 var :%d\n", var);
  pthread_mutex_unlock(&mutex); // 解锁
  pthread_exit(NULL);
}

// 线程2：将变量设置为2
void *set_to_two(void *arg) {
  pthread_mutex_lock(&mutex); // 加锁
  var = 2;
  usleep(1); // 模拟一些处理时间
  printf("thread2 var :%d\n", var);
  pthread_mutex_unlock(&mutex); // 解锁
  pthread_exit(NULL);
}

int main() {
  pthread_t thread1, thread2;
  pthread_mutex_init(&mutex, NULL); // 初始化互斥锁
  pthread_create(&thread1, NULL, set_to_one, NULL);
  pthread_create(&thread2, NULL, set_to_two, NULL);
  pthread_join(thread1, NULL);
  pthread_join(thread2, NULL);
  pthread_mutex_destroy(&mutex); // 销毁互斥锁
  return 0;
}
```

### 2. 条件变量（Condition Variable）

条件变量是一种同步机制，允许线程等待某个条件成立。当条件不满足时，线程可以在条件变量上等待；当条件满足时，其他线程可以通过条件变量通知等待的线程。条件变量通常与互斥锁配合使用。

#### 条件变量API函数表

| 函数名                     | 功能描述             |
| -------------------------- | -------------------- |
| `pthread_cond_init()`      | 初始化条件变量       |
| `pthread_cond_destroy()`   | 销毁条件变量         |
| `pthread_cond_wait()`      | 等待条件变量（阻塞） |
| `pthread_cond_timedwait()` | 带超时的等待条件变量 |
| `pthread_cond_signal()`    | 唤醒一个等待的线程   |
| `pthread_cond_broadcast()` | 唤醒所有等待的线程   |

#### 简单代码示例

**基于之前互斥锁的示例代码，进一步控制线程执行顺序：先执行设置1，设置1执行完了执行设置2**

```c
#include <pthread.h>
#include <stdbool.h>
#include <stdio.h>
#include <unistd.h>
int var = 0;

// 定义一个全局互斥锁
pthread_mutex_t mutex;
// 定义一个全局条件变量
pthread_cond_t cond;

// 线程1：将变量设置为1
void *set_to_one(void *arg) {
  pthread_mutex_lock(&mutex); // 加锁
  var = 1;
  usleep(1); // 模拟一些处理时间
  printf("thread1 var :%d\n", var);
  printf("thread1 signal...\n");
  pthread_cond_signal(&cond);   // 发送条件信号
  pthread_mutex_unlock(&mutex); // 解锁
  pthread_exit(NULL);
}

// 线程2：将变量设置为2
void *set_to_two(void *arg) {
  pthread_mutex_lock(&mutex);       // 加锁
  printf("thread2 waiting...\n");
  pthread_cond_wait(&cond, &mutex); // 等待条件变量
  var = 2;
  usleep(1); // 模拟一些处理时间
  printf("thread2 var :%d\n", var);
  pthread_mutex_unlock(&mutex); // 解锁
  pthread_exit(NULL);
}

int main() {
  pthread_t thread1, thread2;
  pthread_mutex_init(&mutex, NULL); // 初始化互斥锁
  pthread_cond_init(&cond, NULL);   // 初始化条件变量
  pthread_create(&thread1, NULL, set_to_one, NULL);
  pthread_create(&thread2, NULL, set_to_two, NULL);
  pthread_join(thread1, NULL);
  pthread_join(thread2, NULL);
  pthread_mutex_destroy(&mutex); // 销毁互斥锁
  pthread_cond_destroy(&cond);   // 销毁条件变量
  return 0;
}
```

#### 这段代码会有两个问题

##### 1. 信号丢失问题

**现象描述：**
信号丢失是指当生产者线程在消费者线程开始等待之前就发送了通知信号，这个信号会被"丢失"，导致消费者线程可能永远等待下去。这是因为条件变量的通知不会被保存，如果没有线程在等待，通知就会消失。

**解决方法概述：**
设置一个共享变量和条件变量协同使用

##### 2. 虚假唤醒问题

**现象描述：**
虚假唤醒是指线程在条件实际上并未满足的情况下从wait()中被唤醒。这可能由操作系统的实现细节、信号处理或其他系统级事件引起。虚假唤醒是条件变量的固有特性，在任何系统上都可能发生。

**解决方法概述：**
处理虚假唤醒的标准方法是在循环中检查条件

#### 修改后条件变量代码示例

```c
#include <pthread.h>
#include <stdbool.h>
#include <stdio.h>
#include <unistd.h>
int var = 0;

// 定义一个全局互斥锁
pthread_mutex_t mutex;
// 定义一个全局条件变量
pthread_cond_t cond;
// 定义一个标志变量，表示条件是否满足，避免信号丢失
bool ready = false;
// 线程1：将变量设置为1
void *set_to_one(void *arg) {
  pthread_mutex_lock(&mutex); // 加锁
  var = 1;
  usleep(1); // 模拟一些处理时间
  printf("thread1 var :%d\n", var);
  ready = true;
  pthread_cond_signal(&cond);   // 发送条件信号
  pthread_mutex_unlock(&mutex); // 解锁
  pthread_exit(NULL);
}

// 线程2：将变量设置为2
void *set_to_two(void *arg) {
  pthread_mutex_lock(&mutex); // 加锁

  // 使用if会导致虚假唤醒问题
//   if(!ready){
//     pthread_cond_wait(&cond, &mutex);
//   }

  //使用while来避免虚假唤醒 ：如果条件不满足，等待条件变量
  while (!ready) {
    pthread_cond_wait(&cond, &mutex); // 等待条件变量
  }

  var = 2;
  usleep(1); // 模拟一些处理时间
  printf("thread2 var :%d\n", var);
  pthread_mutex_unlock(&mutex); // 解锁
  pthread_exit(NULL);
}

int main() {
  pthread_t thread1, thread2;
  pthread_mutex_init(&mutex, NULL); // 初始化互斥锁
  pthread_cond_init(&cond, NULL);   // 初始化条件变量
  pthread_create(&thread1, NULL, set_to_one, NULL);
  pthread_create(&thread2, NULL, set_to_two, NULL);
  pthread_join(thread1, NULL);
  pthread_join(thread2, NULL);
  pthread_mutex_destroy(&mutex); // 销毁互斥锁
  pthread_cond_destroy(&cond);   // 销毁条件变量
  return 0;
}
```

## 四. 综合示例代码（生产者消费者模型）

生产者消费者模型是多线程编程中的经典问题，展示了如何使用互斥锁和条件变量来协调多个线程的工作。

```c
#include <pthread.h>
#include <stdbool.h>
#include <stdio.h>
#include <unistd.h>
// 定义一个全局互斥锁
pthread_mutex_t mutex;
// 定义一个全局条件变量
pthread_cond_t cond;
// 定义一个全局标志变量
bool ready = false;

// 定义一个全局buffer
char buffer[1024];

// 生产者线程函数
void *producer(void *arg) {
  while (1) {
    // 模拟生产数据
    pthread_mutex_lock(&mutex); // 加锁
    snprintf(buffer, sizeof(buffer), "hello world");
    ready = true;
    pthread_cond_signal(&cond);   // 发送信号，通知消费者
    pthread_mutex_unlock(&mutex); // 解锁
    sleep(1);                     // 模拟生产时间
  }
  pthread_exit(NULL);
}

// 消费者线程函数
void *consumer(void *arg) {
  while (1) {
    pthread_mutex_lock(&mutex); // 加锁
    while (!ready) {
      pthread_cond_wait(&cond, &mutex); // 等待条件变量
    }
    // 消费数据
    printf("Consumed: %s\n", buffer);
    ready = false;
    pthread_mutex_unlock(&mutex); // 解锁
  }
}

int main() {
  pthread_t thread1, thread2;
  pthread_mutex_init(&mutex, NULL);               // 初始化互斥锁
  pthread_cond_init(&cond, NULL);                 // 初始化条件变量
  pthread_create(&thread1, NULL, producer, NULL); // 创建生产者线程
  pthread_create(&thread2, NULL, consumer, NULL); // 创建消费者线程
  pthread_join(thread1, NULL);
  pthread_join(thread2, NULL);
  pthread_mutex_destroy(&mutex); // 销毁互斥锁
  pthread_cond_destroy(&cond);   // 销毁条件变量
  return 0;
}

```
