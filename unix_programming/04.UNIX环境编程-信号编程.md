## 一. 常见信号类型

| 信号名称 | 信号编号 | 默认动作      | 描述                           |
| -------- | -------- | ------------- | ------------------------------ |
| SIGHUP   | 1        | 终止          | 挂起信号，通常在终端断开时发送 |
| SIGINT   | 2        | 终止          | 中断信号，通常由Ctrl+C产生     |
| SIGQUIT  | 3        | 终止+核心转储 | 退出信号，通常由Ctrl+\产生     |
| SIGKILL  | 9        | 终止          | 强制终止信号，不能被捕获或忽略 |
| SIGSEGV  | 11       | 终止+核心转储 | 段错误信号                     |
| SIGPIPE  | 13       | 终止          | 管道破裂信号                   |
| SIGALRM  | 14       | 终止          | 定时器信号                     |
| SIGTERM  | 15       | 终止          | 终止信号，可以被捕获           |
| SIGCHLD  | 17       | 忽略          | 子进程状态改变信号             |
| SIGSTOP  | 19       | 停止          | 停止进程，不能被捕获或忽略     |
| SIGTSTP  | 20       | 停止          | 终端停止信号，通常由Ctrl+Z产生 |
| SIGUSR1  | 30       | 终止          | 用户自定义信号1                |
| SIGUSR2  | 31       | 终止          | 用户自定义信号2                |

### 信号分类：

1. **标准信号**：编号1-31，传统UNIX信号
2. **实时信号**：编号32-64，支持排队和优先级
3. **可靠信号**：实时信号，不会丢失
4. **不可靠信号**：标准信号，可能丢失

## 二. 信号编程

### API函数表

| 函数名          | 功能描述                     |
| --------------- | ---------------------------- |
| `signal()`      | 设置信号处理函数（简单接口） |
| `sigaction()`   | 设置信号处理函数（高级接口） |
| `kill()`        | 向指定进程发送信号           |
| `raise()`       | 向当前进程发送信号           |
| `alarm()`       | 设置定时器信号               |
| `pause()`       | 挂起进程直到收到信号         |
| `sigemptyset()` | 初始化空信号集               |
| `sigfillset()`  | 初始化满信号集               |
| `sigaddset()`   | 向信号集添加信号             |
| `sigdelset()`   | 从信号集删除信号             |
| `sigismember()` | 检查信号是否在信号集中       |
| `sigprocmask()` | 设置进程信号屏蔽字           |
| `sigpending()`  | 获取被阻塞的信号集           |
| `sigsuspend()`  | 临时替换信号屏蔽字并挂起     |

### 代码示例

#### 1. 信号屏蔽示例

```c
#include <stdio.h>
#include <signal.h>
#include <unistd.h>

void sigint_handler(int sig) {
    printf("\n处理SIGINT信号\n");
}

int main() {
    sigset_t newmask, oldmask, pendmask;

    // 设置信号处理函数
    signal(SIGINT, sigint_handler);

    // 初始化信号集
    sigemptyset(&newmask);
    sigaddset(&newmask, SIGINT);

    printf("阻塞SIGINT信号5秒...\n");

    // 阻塞SIGINT信号
    if (sigprocmask(SIG_BLOCK, &newmask, &oldmask) < 0) {
        perror("sigprocmask");
        return 1;
    }

    sleep(5);

    // 检查被阻塞的信号
    if (sigpending(&pendmask) < 0) {
        perror("sigpending");
        return 1;
    }

    if (sigismember(&pendmask, SIGINT)) {
        printf("SIGINT信号被阻塞中\n");
    }

    printf("恢复SIGINT信号处理...\n");

    // 恢复原来的信号屏蔽字
    if (sigprocmask(SIG_SETMASK, &oldmask, NULL) < 0) {
        perror("sigprocmask");
        return 1;
    }

    while(1) {
        pause();
    }

    return 0;
}
```

#### 2. 定时器信号示例

```c
#include <stdio.h>
#include <signal.h>
#include <stdlib.h>
#include <unistd.h>

int alarm_count = 0;

void alarm_handler(int sig) {
    alarm_count++;
    printf("定时器触发第 %d 次\n", alarm_count);

    if (alarm_count < 5) {
        alarm(2);  // 重新设置2秒定时器
    } else {
        printf("定时器结束\n");
        exit(0);
    }
}

int main() {
    signal(SIGALRM, alarm_handler);

    printf("启动定时器，每2秒触发一次\n");
    alarm(2);  // 设置2秒定时器

    while(1) {
        pause();
    }

    return 0;
}
```
