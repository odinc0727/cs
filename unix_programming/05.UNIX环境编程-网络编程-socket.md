## 一. 网络编程

### 网络通信的本质

- **进程间通信（IPC）**：网络编程本质上是跨主机的进程间通信
- **地址标识**：IP地址和端口号用于唯一标识网络中的进程
- **协议栈**：TCP/IP和UDP是网络编程的基础

###  网络通信(IPC通信)的方式-socket

Socket（套接字）是网络编程的核心抽象，它提供了一个统一的接口来访问不同的网络协议。
#### socket体现一切皆文件
- **Socket即文件**：每个Socket在系统中都被视为一个特殊的文件
- **统一的I/O接口**：可以使用read()、write()等标准文件操作函数
- **文件描述符管理**：Socket通过文件描述符进行管理和访问
- **文件描述符的代码体现** ：一个整型变量

## 二. 网络编程

### 1. 主机字节序和网络字节序

#### 字节序的概念

字节序是指多字节数据在内存中的存储顺序：

- **大端字节序**：高位字节存储在低地址
- **小端字节序**：低位字节存储在低地址

#### 主机字节序 vs 网络字节序

**主机字节序**：
 - 主机所规定的字节序

**网络字节序**：
- 网络协议规定的字节序


### 2.  核心结构体

#### 1. sockaddr（通用地址结构体）

```c
struct sockaddr {
    sa_family_t sa_family;    // 地址族（AF_INET, AF_INET6等）
    char sa_data[14];         // 地址数据
};
```

- **用途**：所有地址结构体的基类
- **特点**：通常不直接使用，而是强制转换其他具体的地址结构体

#### 2. sockaddr_in（IPv4地址结构体）

```c
struct sockaddr_in {
    sa_family_t sin_family;      // 地址族，设置为AF_INET
    in_port_t sin_port;          // 端口号（网络字节序）
    struct in_addr sin_addr;     // IPv4地址
    unsigned char sin_zero[8];   // 填充字节，保持与sockaddr相同大小
};
```

- **用途**：IPv4网络编程中最常用的地址结构体
- **重要字段**：
  - `sin_family`：必须设置为 `AF_INET`
  - `sin_port`：端口号，需要用 `htons()` 转换
  - `sin_addr`：IPv4地址结构体

#### 3. in_addr（IPv4地址结构体）

```c
struct in_addr {
    in_addr_t s_addr;    // IPv4地址（网络字节序）
};
```

- **用途**：存储32位IPv4地址
- **常用值**：
  - `INADDR_ANY`：绑定到所有可用接口（0.0.0.0）
  - `INADDR_LOOPBACK`：本地回环地址（127.0.0.1）

#### 4. sockaddr_in6（IPv6地址结构体）

```c
struct sockaddr_in6 {
    sa_family_t sin6_family;     // 地址族，设置为AF_INET6
    in_port_t sin6_port;         // 端口号（网络字节序）
    uint32_t sin6_flowinfo;      // 流信息
    struct in6_addr sin6_addr;   // IPv6地址
    uint32_t sin6_scope_id;      // 作用域ID
};
```

- **用途**：IPv6网络编程
- **特点**：支持128位IPv6地址**

### 4.网络通信典型的调用流程

### 服务端流程
- 创建监听的socket，并且进行绑定和监听
- 接受客户端连接
- 通信
- 关闭监听socket

```
socket() → bind() → listen() → accept() → recv()/send() → close()
```

### 客户端流程
- 创建通信socket
- 连接服务端
- 通信
- 关闭通信socket

```
socket() → connect() → send()/recv() → close()
```

### 5. Echo服务端代码示例

```c
#include <arpa/inet.h>
#include <netinet/in.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/socket.h>
#include <unistd.h>

int main() {
  // 第一阶段 服务端监听socket
  // 1.创建socket
  int listen_sock = socket(AF_INET, SOCK_STREAM, 0);
  if (listen_sock == -1) {
    perror("socket");
    exit(EXIT_FAILURE);
  }
  // 2.构造地址结构体
  struct sockaddr_in addr;
  addr.sin_family = AF_INET;
  addr.sin_addr.s_addr = inet_addr("127.0.0.1");
  addr.sin_port = htons(8080);
  // 3.绑定
  if (bind(listen_sock, (struct sockaddr *)&addr, sizeof(addr)) == -1) {
    perror("bind");
    close(listen_sock);
    exit(EXIT_FAILURE);
  }
  // 4.监听
  if (listen(listen_sock, 5) == -1) {
    perror("listen");
    close(listen_sock);
    exit(EXIT_FAILURE);
  }

  // 第二阶段 连接建立
  struct sockaddr_in client_addr;
  socklen_t client_addr_len = sizeof(client_addr);
  int client_sock =
      accept(listen_sock, (struct sockaddr *)&client_addr, &client_addr_len);
  if (client_sock == -1) {
    perror("accept");
    close(listen_sock);
    exit(EXIT_FAILURE);
  }
  printf("Client connected: %s:%d\n", inet_ntoa(client_addr.sin_addr),
         ntohs(client_addr.sin_port));

  // 第三阶段 通信
  char buffer[1024];
  while (1) {
    ssize_t bytes_received = recv(client_sock, buffer, sizeof(buffer), 0);
    if (bytes_received == -1) {
      perror("recv");
      close(client_sock);
      exit(EXIT_FAILURE);
    }
    buffer[bytes_received] = '\0'; // 确保字符串以null结尾
    printf("Received from client: %s\n", buffer);
    if (send(client_sock,buffer,
             bytes_received, 0) == -1) {
      perror("send");
      close(client_sock);
      exit(EXIT_FAILURE);
    }
  }
  close(listen_sock);
}
```

### 简单的客户端代码示例

```c
#include <arpa/inet.h>
#include <netinet/in.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/socket.h>
#include <unistd.h>
int main() {

  // 创建socket
  int sock = socket(AF_INET, SOCK_STREAM, 0);
  if (sock == -1) {
    perror("socket");
    exit(EXIT_FAILURE);
  }

  // 创建ipv4地址结构体
  struct sockaddr_in addr;
  // 初始化协议
  addr.sin_family = AF_INET;
  // 设置ip地址
  addr.sin_addr.s_addr = inet_addr("127.0.0.1");
  // 设置端口号,转换为网络字节序
  addr.sin_port = htons(8080);

  // 连接服务器,需要注意地址结构体需要强制转换成sockaddr*类型
  if (connect(sock, (struct sockaddr *)&addr, sizeof(addr)) == -1) {
    perror("connect");
    close(sock);
    exit(EXIT_FAILURE);
  }
  printf("Connected to server\n");

  // 通信
  while (1) {
    if (send(sock, "hello wolrd", sizeof("hello world"), 0) == -1) {
      perror("send");
      close(sock);
      exit(EXIT_FAILURE);
    }
    char buffer[1024];
    if (recv(sock, buffer, sizeof(buffer), 0) == -1) {
      perror("recv");
      close(sock);
      exit(EXIT_FAILURE);
    }
    printf("Received from server: %s\n", buffer);
    sleep(1);
  }
  close(sock);
}
```

## 三.阻塞IO和非阻塞IO

### 阻塞IO (Blocking I/O)

**定义**：当进程调用某个IO操作时，如果该操作无法立即完成，进程会被挂起（阻塞），直到操作完成后才继续执行。
**特点**：

- 进程在等待IO操作完成期间无法执行其他任务
- 编程模型简单，逻辑清晰
- 可能导致CPU资源浪费（进程被阻塞时无法利用CPU）

### 非阻塞IO (Non-blocking I/O)

**定义**：当进程调用某个IO操作时，无论操作是否能立即完成，系统调用都会立即返回，不会阻塞进程。

**特点**：

- 进程不会被挂起，可以继续执行其他任务
- 需要轮询检查操作状态
- 编程复杂度较高
- 更好的CPU利用率

### unix中设置非阻塞IO的方式

### 1. 通用可以使用fcntl()系统调用动态设置

```c
void set_nonblocking(int fd){
  int flags = fcntl(fd, F_GETFL,0);  //先获取文件描述符本来的属性
  flags  = flags | O_NONBLOCK;       //再按位或上非阻塞属性
  fcntl(fd,F_SETFL ,flags);         //设置
}
```

### 2.直接在open/socket的时候设置

```c
// 打开文件时设置非阻塞模式
int fd = open("file", O_RDONLY | O_NONBLOCK);
// 创建套接字
int sockfd = socket(AF_INET, SOCK_STREAM | O_NONBLOCK, 0);

```
